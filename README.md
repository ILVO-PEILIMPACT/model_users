# PEILIMPACT tool for end users  

Use SWAP-WOFOST together with data layers covering Flanders to launch a simulation for your specific location/case. See the full guidelines in **User manual.pdf**

This model is the first version of SWAP-WOFOST adapted to Flemish conditions. 
The model was developed and is maintained by Wageningen University & Research. 
This version was prepared by ILVO in the context of the project PEILIMPACT. See the full report here: [PEILIMPACT report](https://ilvo_plant-peilimpact_nl.curve.space/).


## Requirements

R version 4.2.1  
SWAP version 4.2.0
